# Comfort Inn - Hotel Website

A modern and fully responsive hotel website built using **HTML5** and **Bootstrap**. It features an interactive navigation bar, comprehensive sections for vegetarian and non-vegetarian menus, dedicated login and registration forms, and an informative footer with location details.

🔗 **Live Demo:** [https://comfort-inn.netlify.app](https://comfort-inn.netlify.app)

### Key Highlights:
- Fully responsive across mobile, tablet, and desktop screens
- Organized veg and non-veg food showcase
- Clean user authentication interface (Login & Register)
- Integrated Google Maps location and contact details
